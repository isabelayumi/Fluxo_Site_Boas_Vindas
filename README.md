# Fluxo Industrial Intelligence

Site institucional em construção para apresentar o projeto Fluxo Industrial Intelligence.

## Estrutura

- `dist/index.html`: conteúdo e seções
- `dist/styles.css`: identidade visual e responsividade
- `dist/script.js`: navegação, menu mobile e animações
- `.openai/hosting.json`: configuração de publicação no Sites

O projeto é estático e não exige instalação. Para visualizar localmente, sirva a pasta `dist` com um servidor HTTP.
